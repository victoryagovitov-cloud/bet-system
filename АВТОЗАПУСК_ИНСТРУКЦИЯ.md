# Инструкция по настройке автозапуска

## Вариант 1: Автоматическая установка (рекомендуется)

### Через PowerShell (от имени администратора):
```powershell
.\setup_windows_service.ps1
```

### Через BAT файл:
```batch
install_autostart.bat
```

Это создаст задачу в Task Scheduler, которая будет запускать систему при старте Windows.

## Вариант 2: Ручная установка через Task Scheduler

1. Открой **Task Scheduler** (Планировщик заданий)
   - Win+R → `taskschd.msc`
   - Или через поиск Windows

2. Создай новую задачу:
   - Справа: **Create Basic Task** (Создать простую задачу)
   - Имя: `TrueLiveBet AutoStart`

3. Настрой триггер:
   - **When the computer starts** (При запуске компьютера)

4. Настрой действие:
   - **Start a program** (Запустить программу)
   - Program/script: `python`
   - Add arguments: `auto_start_service.py`
   - Start in: `D:\cursor\Backtothestart` (твой путь)

5. Дополнительные настройки:
   - Вкладка **General**:
     - ✅ Run whether user is logged on or not
     - ✅ Run with highest privileges
   - Вкладка **Settings**:
     - ✅ Allow task to be run on demand
     - ✅ Run task as soon as possible after a scheduled start is missed

6. Сохрани задачу

## Вариант 3: Через автозагрузку Windows

1. Нажми **Win+R**
2. Введи: `shell:startup`
3. Создай ярлык на файл `start_reliable_system.bat`
4. Готово!

**Минус:** Запускается только когда пользователь входит в систему.

## Вариант 4: Ручной запуск через Python

Просто запусти:
```bash
python auto_start_service.py
```

Этот скрипт:
- Проверит, не запущены ли компоненты
- Запустит watchdog и планировщик
- Запишет логи в `logs/startup.log`

## Проверка автозапуска

### Проверить задачу в Task Scheduler:
```powershell
Get-ScheduledTask -TaskName "TrueLiveBet AutoStart"
```

### Проверить статус системы:
```bash
python system_monitor.py
```

Или:
```batch
check_system_status.bat
```

### Проверить логи:
- `logs/startup.log` - логи автозапуска
- `logs/auto_cycle.log` - логи планировщика
- `logs/watchdog.log` - логи watchdog

## Удаление автозапуска

### Через PowerShell:
```powershell
Unregister-ScheduledTask -TaskName "TrueLiveBet AutoStart" -Confirm:$false
```

### Через Task Scheduler:
1. Открой Task Scheduler
2. Найди задачу `TrueLiveBet AutoStart`
3. Удали её

## Что запускается автоматически

1. **Watchdog Service** (`watchdog_service.py`)
   - Проверяет планировщик каждую минуту
   - Автоматически перезапускает при падении

2. **Scheduler** (`auto_cycle_scheduler.py`)
   - Основной планировщик анализа
   - Запускается по расписанию каждые 45 минут

## Порядок запуска

1. Сначала запускается **Watchdog** (задержка 2 сек)
2. Затем запускается **Scheduler** (задержка 5 сек)

Это гарантирует, что watchdog успеет инициализироваться до планировщика.

## Логи автозапуска

Все действия записываются в `logs/startup.log`:
- Время запуска каждого компонента
- Результаты запуска (успех/ошибка)
- PID процессов

## Рекомендации

1. **Используй Task Scheduler** (Вариант 1 или 2) - запускается даже без входа пользователя
2. **Проверяй логи** после первого автозапуска
3. **Настрой мониторинг** - периодически проверяй `system_monitor.py`
4. **Держи Python в PATH** - чтобы Task Scheduler мог найти `python`

## Устранение проблем

### Задача не запускается:
- Проверь права администратора
- Убедись, что Python в PATH
- Проверь логи в `logs/startup.log`

### Компоненты не запускаются:
- Проверь, не запущены ли они уже вручную
- Удали lock файлы (`.auto_cycle.lock`, `.watchdog.lock`)
- Проверь логи компонентов

### Автозапуск работает, но система не работает:
- Запусти `system_monitor.py` для диагностики
- Проверь доступность API (Scores24, Telegram)
- Проверь логи всех компонентов
