## 🔧 ТЕХНИЧЕСКИЕ РЕШЕНИЯ

### Проблема: TLS сертификаты
**Решение:** Использование `certifi.where()` в Python скриптах

### Проблема: Таймауты Selenium
**Решение:** 
```python
# Оптимизация драйвера
pageLoadStrategy='eager'  # Не ждет полной загрузки
prefs = {
    "profile.managed_default_content_settings.images": 2,  # Блок изображений
    "profile.managed_default_content_settings.stylesheets": 2  # Блок CSS
}

# Retry с остановкой загрузки
driver.execute_script("window.stop();")
```

### Проблема: Различия в названиях команд
**Решение:** Алгоритм сопоставления по турниру + счету + времени (документировано в памяти)
