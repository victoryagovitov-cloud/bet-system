# 🔍 КАК ПРОВЕРИТЬ НАСТРОЙКИ BROWSER MCP В CURSOR

## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ

### ШАГ 1: ОТКРЫТЬ НАСТРОЙКИ CURSOR

**Способ 1 (горячая клавиша):**
```
Ctrl + ,  (запятая)
```

**Способ 2 (через меню):**
```
File → Preferences → Settings
```

**Способ 3 (командная палитра):**
```
Ctrl + Shift + P
→ ввести "Preferences: Open Settings"
→ Enter
```

---

### ШАГ 2: НАЙТИ РАЗДЕЛ MCP ИЛИ BROWSER

**Вариант A: Поиск по названию**
1. В поле поиска настроек ввести:
   - `MCP`
   - `Browser`
   - `Model Context Protocol`
   - `mcp browser`

2. Проверить найденные результаты

**Вариант B: Ручной поиск**
1. В левом меню настроек найти:
   - `Extensions`
   - `Features`
   - `MCP` или `Model Context Protocol`
   - `Browser`

**Вариант C: Файл конфигурации**
1. Открыть командную палитру: `Ctrl + Shift + P`
2. Ввести: `Preferences: Open User Settings (JSON)`
3. Проверить наличие секции:
```json
{
  "mcp": {
    ...
  }
}
```
или
```json
{
  "mcpServers": {
    "browser": {
      ...
    }
  }
}
```

---

### ШАГ 3: ПРОВЕРИТЬ НАЛИЧИЕ ОПЦИЙ

**Что искать:**

**1. Опции запуска браузера:**
```json
{
  "mcpServers": {
    "browser": {
      "args": [...],
      "launchOptions": {...},
      "browserArgs": [...]
    }
  }
}
```

**2. Опции блокировки ресурсов:**
```json
{
  "browser": {
    "blockImages": true,
    "blockCss": true,
    "blockFonts": true
  }
}
```

**3. Chrome/Chromium флаги:**
```json
{
  "browser": {
    "chromeArgs": [
      "--disable-images",
      "--disable-css"
    ]
  }
}
```

---

### ШАГ 4: ЕСЛИ ОПЦИЙ НЕТ - ПРОВЕРИТЬ ДОКУМЕНТАЦИЮ

**Где искать:**
1. **В Cursor:**
   - Помощь → Документация
   - Поиск: "Browser MCP configuration"

2. **В GitHub:**
   - Репозиторий Cursor
   - Поиск: "mcp browser configuration"

3. **В настройках MCP:**
   - Открыть командную палитру: `Ctrl + Shift + P`
   - Ввести: `MCP` или `Model Context Protocol`
   - Проверить доступные команды настройки

---

### ШАГ 5: ПРОВЕРИТЬ ЧЕРЕЗ КОНСОЛЬ/ЛОГИ

**Если настройки не найдены в UI:**

1. **Открыть DevTools Cursor:**
   ```
   Help → Toggle Developer Tools
   или
   Ctrl + Shift + I
   ```

2. **Проверить консоль:**
   - Найти логи загрузки Browser MCP
   - Проверить аргументы запуска браузера

3. **Проверить Network:**
   - Открыть вкладку Network
   - Запустить анализ
   - Посмотреть какие ресурсы загружаются

---

## 🔍 АЛЬТЕРНАТИВНЫЕ МЕТОДЫ ПРОВЕРКИ

### МЕТОД 1: Проверка через команды MCP

**Попробовать передать опции в команду:**
```
mcp_browsermcp_browser_navigate(
  url="https://betboom.ru/...",
  options={
    "block_images": true,
    "block_css": true
  }
)
```

**Проверить:**
- Принимает ли функция дополнительные параметры?
- Есть ли ошибки при передаче опций?

### МЕТОД 2: Проверка конфигурационного файла

**Путь к конфигу Cursor (Windows):**
```
%APPDATA%\Cursor\User\settings.json
или
%USERPROFILE%\AppData\Roaming\Cursor\User\settings.json
```

**Что проверить:**
1. Открыть файл `settings.json`
2. Найти секции:
   - `mcp`
   - `mcpServers`
   - `browser`
3. Проверить наличие опций

## 📝 ЧТО ДЕЛАТЬ ПОСЛЕ ПРОВЕРКИ

### ✅ ЕСЛИ ОПЦИИ НАЙДЕНЫ:

**Добавить флаги блокировки:**
```json
{
  "mcpServers": {
    "browser": {
      "args": [
        "--disable-images",
        "--disable-css",
        "--disable-fonts",
        "--blink-settings=imagesEnabled=false"
      ]
    }
  }
}
```

**Протестировать:**
1. Перезапустить Cursor
2. Запустить анализ 1 матча
3. Замерить время загрузки
4. Сравнить с текущим

### ❌ ЕСЛИ ОПЦИЙ НЕТ:

**Использовать текущую оптимизацию:**
- ✅ Умная проверка готовности (5 сек)
- ✅ Экономия 30-40% времени
- ✅ Это уже хороший результат!

**Альтернатива:**
- Сосредоточиться на других оптимизациях
- Использовать кеширование
- Оптимизировать алгоритм парсинга
