# Как повысить надежность системы

## Что было сделано

### ✅ 1. Таймауты для планировщика
- Анализ не может зависнуть больше 10 минут
- Автоматическое логирование таймаутов
- Отслеживание последовательных ошибок

### ✅ 2. Система мониторинга (`system_monitor.py`)
- Проверка статуса планировщика
- Проверка последней активности
- Проверка доступности API (Scores24, Telegram)
- Автоматические алерты в Telegram при проблемах

### ✅ 3. Watchdog сервис (`watchdog_service.py`)
- Автоматический перезапуск планировщика при падении
- Проверка каждую минуту
- Максимум 3 попытки с паузой 5 минут

### ✅ 4. Улучшенная обработка ошибок
- Все ошибки логируются
- Критические алерты при превышении лимита
- Graceful shutdown (корректное завершение)

## Как использовать

### Простой запуск (рекомендуется)
```bash
start_reliable_system.bat
```

Этот файл запустит:
- Watchdog (автоматический перезапуск)
- Планировщик (основной процесс)

### Проверка статуса
```bash
check_system_status.bat
```

Или вручную:
```bash
python system_monitor.py
```

### Ручной запуск компонентов

**Только планировщик:**
```bash
python auto_cycle_scheduler.py
```

**С watchdog (рекомендуется):**
```bash
# Терминал 1
python watchdog_service.py

# Терминал 2
python auto_cycle_scheduler.py
```

**Мониторинг:**
```bash
python system_monitor.py
```

## Что проверяет мониторинг

1. **Планировщик запущен?** - Проверяет lock файл и процесс
2. **Была ли активность?** - Последняя запись в логе не старше часа
3. **API доступны?** - Scores24 и Telegram отвечают
4. **Есть ли место на диске?** - Минимум 1 GB свободно

## Логи

Все логи в папке `logs/`:
- `auto_cycle.log` - логи планировщика
- `watchdog.log` - логи watchdog
- `health_check.log` - логи мониторинга

## Статус системы

Файл `.system_status.json` содержит:
- Время последней проверки
- Результаты всех проверок
- Количество критических проблем и предупреждений

## Настройка

### Изменить таймаут анализа
В `auto_cycle_scheduler.py`:
```python
CYCLE_TIMEOUT = 600  # 10 минут (измени на нужное значение)
```

### Изменить количество попыток перезапуска
В `watchdog_service.py`:
```python
MAX_RESTART_ATTEMPTS = 3  # Максимум попыток
RESTART_COOLDOWN = 300  # 5 минут между попытками
```

### Изменить канал для алертов
В `system_monitor.py`:
```python
ALERT_CHAT_ID = "@TrueLiveBet"  # Можно изменить на личный чат
```

## Что делать при проблемах

1. **Планировщик не запускается:**
   - Проверь `logs/auto_cycle.log`
   - Убедись, что нет другого запущенного экземпляра
   - Удали `.auto_cycle.lock` если нужно

2. **Много ошибок:**
   - Проверь `logs/auto_cycle.log` на детали
   - Проверь доступность Scores24 и Telegram
   - Запусти `system_monitor.py` для диагностики

3. **Watchdog не перезапускает:**
   - Проверь `logs/watchdog.log`
   - Убедись, что watchdog запущен
   - Проверь, что планировщик действительно упал

## Автозапуск при старте Windows

1. Создай задачу в Task Scheduler
2. Триггер: "При запуске компьютера"
3. Действие: запустить `start_reliable_system.bat`
4. Опции: "Запускать с наивысшими правами" (если нужно)

Или добавь `start_reliable_system.bat` в автозагрузку Windows.

## Рекомендации

1. **Запускай с watchdog** - это гарантирует автоматический перезапуск
2. **Периодически проверяй статус** - раз в день запускай `check_system_status.bat`
3. **Следи за логами** - если видишь много ошибок, проверь причину
4. **Настрой внешний мониторинг** - можно использовать UptimeRobot для проверки каждые 5 минут
