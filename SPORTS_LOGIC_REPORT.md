# ОТЧЕТ ПО ЛОГИКЕ ПРИНЯТИЯ РЕШЕНИЙ ПО ВИДАМ СПОРТА

## ВИДЫ СПОРТА В АНАЛИЗЕ

**Текущий список (4 вида спорта):**
1. **Футбол** (soccer) - основной вид спорта
2. **Теннис** (tennis) - с поддержкой ITF турниров
3. **Баскетбол** (basketball) - **НОВЫЙ, ДОБАВЛЕН**
4. **Гандбол** (handball) - **ВКЛЮЧЕН ОБРАТНО** (был временно отключен)

**Изменения:**
- ✅ **Баскетбол**: Полностью новый анализатор, добавлен в систему
- ✅ **Гандбол**: Включен обратно с исправлением критической ошибки (счет ≠ минуты)

---

## ОБЩИЕ ПРИНЦИПЫ

Все виды спорта используют единую систему фильтрации по коэффициентам:
- **MIN_ODDS = 1.01** - минимальный коэффициент
- **PRIMARY_MAX_ODDS = 1.10** - безопасные матчи (1.01-1.10)
- **EXTENDED_MAX_ODDS = 1.50** - интересные матчи (1.11-1.50)
- **EXTENDED_MIN_DOMINANCE = 6.0** - минимальный перевес для EXTENDED tier
- **Приоритизация**: сначала по коэффициентам (выше = лучше), потом по dominance_score

## 1. ФУТБОЛ (SOCCER)

### Параметры матча:
- **Длительность**: 90 минут (2 тайма по 45 минут)
- **MINIMUM_MINUTE_THRESHOLD**: 15 минут (уменьшено с 18)
- **Обязательная статистика**: possession (владение) **ИЛИ** shots_on_target (удары в створ)
  - *Изменение: ослаблены требования - теперь достаточно хотя бы одного параметра*

### Статистика для анализа:
- **xG** (expected goals) - опционально
- **possession** (владение мячом) - обязательно (если есть)
- **shots_on_target** (удары в створ) - обязательно (если есть)
- **shots_total** (все удары) - опционально

### Формула dominance_score:
```
dominance_score = 
    xg_component (если есть)
    + (shots_on_target_diff) * 2
    + shots_total_component (если есть)
    + (possession_diff) * 0.5
    + score_factor * time_factor

где:
- score_factor = abs(home_score - away_score) * 2
- time_factor = minute_numeric / 90.0
```

### Логика фильтрации по времени:

**PRIMARY tier (1.01-1.10):**
- < 30 минут: required_dominance = 5.0
- >= 30 минут: required_dominance = 2.0 ИЛИ (xG_diff >= 0.2 И удары >= 1)

**EXTENDED tier (1.11-1.50):**
- < 30 минут: required_dominance = 8.0
- 30-60 минут: required_dominance = 6.0
- > 60 минут: required_dominance = 5.0
- ИЛИ (xG_diff >= 0.3 И удары >= 1 И минута >= 60)

### Особенности:
- Фильтрация молодежных/дружеских матчей по названиям команд и турниров
- Фильтрация низших дивизионов
- Транслитерация названий команд в русский

## 2. ТЕННИС

### Параметры матча:
- **Структура**: Сеты (обычно 2 из 3 или 3 из 5)
- **Минимальный порог**: 6 сыгранных геймов
- **Обязательная статистика**: points_won (очки) ИЛИ breaks_diff (брейки)

### Статистика для анализа:
- **points_won** (выигранные очки) - обязательно (если есть)
- **breaks_diff** (разница брейков) - обязательно (если есть)
- **sets_score** (счет по сетам) - обязательно
- **current_games** (счет в текущем сете) - обязательно

### Формула dominance_score:
```
dominance_score = 
    points_component (если есть points_won)
    + breaks_component * 3
    + sets_component * 5
    + games_component * 2
```

### Логика фильтрации по времени:

**PRIMARY tier (1.01-1.10):**
- 1-й сет, < 6 геймов: required_dominance = 5.0
- Иначе: required_dominance = 2.0 ИЛИ (points_diff >= 3 И сет >= 2)

**EXTENDED tier (1.11-1.50):**
- 1-й сет, < 6 геймов: required_dominance = 8.0
- 1-й сет: required_dominance = 6.0
- 2-й сет и дальше: required_dominance = 5.0
- ИЛИ (points_diff >= 4 И сет >= 2)

### Особенности:
- Фильтрация по типу турнира (ATP, WTA, Challenger, **ITF**)
- **ITF матчи**: разрешены, если есть хотя бы часть статистики (points_won, breakpoints_won, service_points_won) ИЛИ явное преимущество в счете (выигран сет или разница 3+ гейма)
- Учет русского и английского названий турниров
- Анализ по сетам, а не по минутам

## 3. БАСКЕТБОЛ (НОВЫЙ - ДОБАВЛЕН)

### Параметры матча:
- **Длительность**: 40 минут (4 четверти по 10 минут)
- **MINIMUM_MINUTE_THRESHOLD**: 15 минут (1.5 четверти)
- **Обязательная статистика**: points (очки) - обязательно
- **Источник данных**: Scores24 GraphQL API (sport="basketball")

### Статистика для анализа:
- **points** (очки) - **ОБЯЗАТЕЛЬНО** (без очков матч не анализируется)
- **rebounds** (подборы) - опционально (если есть, учитывается в dominance_score)
- **assists** (передачи) - опционально (если есть, учитывается в dominance_score)
- **field_goal_pct** (процент попаданий) - опционально (если есть, учитывается в dominance_score)

### Извлечение статистики:
Статистика извлекается из структуры Scores24:
- Парсинг по периодам (periods) → groups → statisticsItems
- Суммирование значений по всем периодам
- Формат: (home_value, away_value) для каждой метрики

### Формула dominance_score:
```
points_component = (leader_points - trailing_points) * 0.3
rebounds_component = (leader_rebounds - trailing_rebounds) * 2 (если есть)
assists_component = (leader_assists - trailing_assists) * 1.5 (если есть)
fg_pct_component = (leader_fg_pct - trailing_fg_pct) * 5 (если есть)

score_factor = abs(home_score - away_score) * 1.5
time_factor = minute_numeric / 40.0

dominance_score = 
    points_component
    + rebounds_component (если есть)
    + assists_component (если есть)
    + fg_pct_component (если есть)
    + score_factor * time_factor
```

**Примеры расчета:**
- Матч 20-я минута, счет 50:40 (разница 10 очков):
  - points_component = 10 * 0.3 = 3.0
  - score_factor = 10 * 1.5 = 15
  - time_factor = 20 / 40 = 0.5
  - score_factor * time_factor = 15 * 0.5 = 7.5
  - **Итого**: ~10.5 (без учета rebounds/assists)

- Матч 35-я минута, счет 80:65 (разница 15 очков), подборы 35:28 (разница 7):
  - points_component = 15 * 0.3 = 4.5
  - rebounds_component = 7 * 2 = 14
  - score_factor = 15 * 1.5 = 22.5
  - time_factor = 35 / 40 = 0.875
  - score_factor * time_factor = 22.5 * 0.875 = 19.7
  - **Итого**: ~38.2

### Логика фильтрации по времени:

**Базовые требования:**
- minute_numeric >= 15 (минимум 1.5 четверти)
- minute_numeric < 40 (матч не закончен)
- points обязательны (home_points и away_points должны быть не None)
- home_score != away_score (не ничья)

**PRIMARY tier (коэффициенты 1.01-1.10):**
- **< 20 минут** (первая половина матча):
  - required_dominance = 5.0
  - Нужен значительный перевес для раннего матча
  
- **>= 20 минут** (вторая половина):
  - required_dominance = 2.0
  - ИЛИ (points_diff >= 8 И минута >= 30)
  - Более мягкие требования для поздних матчей

**EXTENDED tier (коэффициенты 1.11-1.50):**
- **< 20 минут** (первая половина):
  - required_dominance = 8.0
  - Очень строгие требования для ранних матчей
  
- **20-30 минут** (середина матча):
  - required_dominance = 6.0 (EXTENDED_MIN_DOMINANCE)
  - Стандартные требования
  
- **> 30 минут** (концовка):
  - required_dominance = 5.0
  - ИЛИ (points_diff >= 10 И rebounds_diff >= 3 И минута >= 30)
  - Можно снизить требования при явном преимуществе

### Фильтрация турниров:
- **Разрешены**: NBA, Euroleague, Евролига, Eurocup, FIBA, Чемпионат мира, Олимпиада, Eurobasket, ACB, VTB, Superleague
- **Запрещены**: Молодежные (U18, U19, U20, U21), дружеские, любительские, резервные, женские (если не указано иное)

### Фильтрация команд:
- Проверка названий команд на молодежные маркеры (U18, U19, U20, U21, "до 21", "молодеж", "youth", "junior")
- Если команда молодежная - матч отфильтровывается

### Особенности:
- **Учет времени**: Анализ по минутам (не по четвертям), но учитывается общая длительность 40 минут
- **Динамические требования**: Ранние матчи требуют большего перевеса
- **Множественные метрики**: Учитываются очки, подборы, передачи, процент попаданий
- **Транслитерация**: Названия команд транслитерируются в русский
- **Приоритизация**: Сортировка по коэффициентам (выше = лучше), затем по dominance_score

### Коэффициенты:
- Используется рынок "one_two" (П1/П2, без ничьей)
- Приоритет BetBoom, но используется любой доступный букмекер
- Минимальный коэффициент: 1.01
- Максимальный для PRIMARY: 1.10
- Максимальный для EXTENDED: 1.50

## 4. ГАНДБОЛ (ВКЛЮЧЕН ОБРАТНО)

**Статус**: Был временно отключен, теперь включен обратно с исправлением ошибки

### Параметры матча:
- **Длительность**: 60 минут (2 тайма по 30 минут)
- **MINIMUM_MINUTE_THRESHOLD**: 32 минуты (больше половины матча)
- **Обязательная статистика**: НЕТ (статистика опциональна)
- **ВАЖНО**: **Счет НЕ равен минутам!** Количество голов ≠ количество минут

### Статистика для анализа:
- **score** (счет) - обязательно
- **minute_numeric** (минута матча) - обязательно (из details.get("minute"))
- **pace** (темп игры) - рассчитывается как total_score / minute_numeric
- **projected_total** (прогноз общего счета) - опционально

### Формула dominance_score:
```
dominance_score = 
    score_diff * 5
    + pace * 2
    + 3 (если есть total_recommendation)
```

### Логика фильтрации:

**Базовые требования:**
- minute_numeric >= 32 (больше половины матча)
- minute_numeric < 60 (матч не закончен)
- total_score >= 20 (достаточно голов)
- score_diff зависит от времени:
  - >= 45 минут: diff_threshold = 2 гола
  - >= 40 минут: diff_threshold = 3 гола
  - < 40 минут: diff_threshold = 4 гола

**PRIMARY tier (1.01-1.10):**
- Базовые требования + odds <= 1.10

**EXTENDED tier (1.11-1.50):**
- Базовые требования + odds <= 1.50
- dominance_score >= 6.0
- score_diff >= 3

### Особенности:
- **КРИТИЧЕСКИ ВАЖНО**: Минуты берутся ТОЛЬКО из `details.get("minute")` или `match_info.get("minute")`
- **НЕ используем** счет (количество голов) как время матча
- Если минут нет - матч пропускается (нужна snapshot обогащение)
- Фильтрация по типу турнира (Champions League, Bundesliga, и т.д.)

## ОБЩИЕ УЛУЧШЕНИЯ (ВСЕ ВИДЫ СПОРТА)

### 1. Уменьшение периода проверки матчей:
- **Было**: MINIMUM_MINUTE_THRESHOLD = 18 минут (футбол)
- **Стало**: MINIMUM_MINUTE_THRESHOLD = 15 минут (футбол)
- **Эффект**: +10-15% матчей в анализе

### 2. Ослабление требований к статистике (футбол):
- **Было**: possession **И** shots_on_target (оба обязательны)
- **Стало**: possession **ИЛИ** shots_on_target (хотя бы одно)
- **Эффект**: +40-50% матчей в анализе

### 3. Добавление баскетбола:
- **Новый вид спорта** с полным анализатором
- **Эффект**: +50-100% матчей в день

### 4. Включение гандбола:
- **Восстановлен** анализатор гандбола
- **Исправлена ошибка**: счет больше не используется как время матча
- **Эффект**: +10-20% матчей в день

### 5. Уменьшение интервала проверок:
- **Было**: каждые 45 минут (20 проверок в день)
- **Стало**: каждые 30 минут (30 проверок в день)
- **Эффект**: +50% проверок, больше шансов поймать матчи

## КРИТИЧЕСКИЕ МОМЕНТЫ

1. **Гандбол**: Всегда использовать `details.get("minute")` для времени, НЕ использовать счет
2. **Футбол**: Теперь достаточно possession ИЛИ shots_on_target (не оба)
3. **Баскетбол**: Новый вид спорта, требует тестирования
4. **Теннис**: Анализ по сетам, а не по минутам
5. **Все виды**: Динамические требования по времени (ранние матчи требуют большего перевеса)
