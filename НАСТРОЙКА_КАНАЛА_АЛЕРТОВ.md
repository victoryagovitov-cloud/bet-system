# Настройка канала для критических алертов

## 📋 Описание

Критические сообщения системы (ошибки планировщика, проблемы с API, и т.д.) теперь отправляются в **отдельный канал**, а не в основной канал со ставками `@TrueLiveBet`.

## 🔧 Настройка

### Вариант 1: Создать новый канал для алертов

1. Создай новый канал в Telegram (например, `@TrueLiveBetAlerts`)
2. Добавь бота в канал как администратора
3. Укажи username канала в `system_monitor.py`:
   ```python
   ALERT_CHAT_ID = "@TrueLiveBetAlerts"
   ```

### Вариант 2: Использовать личный чат

1. Узнай свой chat_id:
   - Напиши боту @userinfobot
   - Или используй @getidsbot
2. Укажи chat_id в `system_monitor.py`:
   ```python
   ALERT_CHAT_ID = "123456789"  # Твой chat_id
   ```

### Вариант 3: Использовать переменную окружения

1. Создай переменную окружения `ALERTS_CHAT_ID`:
   ```bash
   # Windows PowerShell
   $env:ALERTS_CHAT_ID = "@TrueLiveBetAlerts"
   
   # Windows CMD
   set ALERTS_CHAT_ID=@TrueLiveBetAlerts
   ```

2. Или добавь в системные переменные окружения Windows

## 📝 Текущая настройка

**По умолчанию:** `ALERT_CHAT_ID = None` (алерты не отправляются в Telegram, только логируются)

**Чтобы включить отправку алертов:**
1. Создай канал для алертов (например, `@TrueLiveBetAlerts`) или используй личный chat_id
2. Добавь бота в канал как администратора (если используешь канал)
3. Укажи канал одним из способов:
   - Прямо в `system_monitor.py`: `ALERT_CHAT_ID = "@TrueLiveBetAlerts"`
   - Через переменную окружения: `set ALERTS_CHAT_ID=@TrueLiveBetAlerts`

## ✅ Проверка

После настройки запусти:
```bash
python system_monitor.py
```

Если есть критические проблемы, они отправятся в указанный канал алертов, а не в `@TrueLiveBet`.

## 🔍 Где используется

- `system_monitor.py` - отправка критических алертов о состоянии системы
- Все критические сообщения идут только в канал алертов
- Основной канал `@TrueLiveBet` используется только для ставок
