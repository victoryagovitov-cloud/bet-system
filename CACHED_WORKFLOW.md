# 🔄 КЕШИРОВАННЫЙ АЛГОРИТМ АНАЛИЗА (ОБНОВЛЕН 09.11.2025)

## 🎯 КОМАНДЫ
- **🎯F** — футбол (используется по умолчанию)

## ⚙️ БАЗОВЫЕ УСЛОВИЯ
- Запускаем анализ **только из Cursor** с активным MCP Browser. Запуск через PowerShell запрещён — скрипт останавливается без отправки.
- MCP вкладку держим подключённой постоянно; повторно подключаться не требуется.
- Анализируем **все** live-матчи футбола с неничейным счётом, кроме турниров из запретного списка (ACL, форматы 5x5/3x3, женские/молодёжные/резервные лиги, 3-й и 4-й дивизионы).
- Ограничения по коэффициентам снимаются: задача — проверить каждый оставшийся матч по статистике.

## ⚡ УСКОРЕННЫЙ ЦИКЛ (≤5 МИНУТ)
1. **Быстрый скан BetBoom**
   - Снимаем snapshot live-футбола.
   - Фиксируем все неничейные матчи.
   - Отбрасываем только явные запреты (ACL, 5x5/3x3, женские/молодёжные/резервные, 3-й/4-й дивизионы).

2. **Мгновенная проверка Scores24**
   - Сразу переходим на live-список `scores24.live/ru/soccer?matchesFilter=live`.
   - По найденному матчу извлекаем прямой URL и открываем страницу.
   - Снимаем **только ключевой блок**: счёт, время, владение, удары, удары в створ, таблица (позиции команд). Остальные разделы не листаем.
   - Если live-статистика отсутствует — сразу пропускаем матч и двигаемся дальше.

3. **Фиксация и отправка**
   - Как только первый матч подтверждён статистикой — формируем сообщение по шаблону и отправляем.
   - Сообщение формируется из одного источника (в `send_verified_matches.py`) и использует ротируемый дисклеймер.
   - Сразу после отправки продолжаем мониторинг оставшихся матчей и собираем следующую рекомендацию.

4. **Контроль времени**
   - Если прошло **4–5 минут** с момента команды, а подтверждён только один матч — отправляем его незамедлительно и отчётно продолжаем поиск.
   - В каждом цикле в чате отмечаем текущую стадию (BetBoom → Scores24 → Отправка → Мониторинг).

## 📬 ФОРМАТ ОТПРАВКИ
- Заголовок: `🎯 LIVE-АНАЛИЗ • {время} МСК, {дата}`
- По видам спорта используем закреплённые блоки (сейчас только футбол).
- Для каждого матча: порядковый номер, полные названия команд, турнир, счёт+время, рекомендация с коэфом, краткая аналитика.
- Дисклеймер подтягиваем из ротации (`ДИСКЛЕЙМЕРЫ_ДЛЯ_СООБЩЕНИЙ.txt`).

## ✅ ЧТО ЗАПРЕЩЕНО
- Запускать скрипты через PowerShell/терминал вне Cursor.
- Ждать накопления нескольких матчей, если уже есть подтверждённый один.
- Пролистывать полностью страницы Scores24 — берём только нужные строки.
- Указывать в сообщениях технические критерии отбора или источники.

## 🕒 ПОСЛЕ ОТПРАВКИ
- Продолжаем мониторинг live-листа в MCP Browser.
- При появлении нового подходящего матча повторяем цикл (сбор → проверка → отправка) без задержек.
- Если новых матчей нет, оставляем в чате заметку и ждём следующего окна по расписанию.
- Нет подходящих матчей → сразу отправляем сообщение об отсутствии и ждём следующую команду.
- Каждая команда AHK завершается сообщением в канал: либо прогнозы, либо уведомление «подходящих нет».
