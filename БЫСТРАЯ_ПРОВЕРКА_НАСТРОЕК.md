# ⚡ БЫСТРАЯ ПРОВЕРКА НАСТРОЕК CURSOR

## 🎯 САМЫЙ БЫСТРЫЙ СПОСОБ

### ШАГ 1: ОТКРЫТЬ НАСТРОЙКИ
```
Нажми: Ctrl + ,  (запятая)
```

### ШАГ 2: ПОИСК
В поле поиска вверху введите:
```
MCP
```
или
```
Browser
```
или
```
mcp browser
```

### ШАГ 3: ПРОВЕРКА РЕЗУЛЬТАТОВ

**Если найдены настройки:**
- Ищите опции:
  - `Browser launch arguments`
  - `Chrome flags`
  - `Disable images`
  - `MCP server configuration`

**Если ничего не найдено:**
- Возможно, настройки находятся в другом месте
- См. альтернативные методы ниже

---

## 📁 АЛЬТЕРНАТИВА: ПРОВЕРКА ЧЕРЕЗ JSON

### ШАГ 1: ОТКРЫТЬ JSON ФАЙЛ НАСТРОЕК

**В Cursor:**
```
Ctrl + Shift + P
→ ввести: "Preferences: Open User Settings (JSON)"
→ Enter
```

### ШАГ 2: ПРОВЕРИТЬ НАЛИЧИЕ СЕКЦИЙ

**Ищите следующие секции:**
```json
{
  "mcp": { ... },
  
  "mcpServers": {
    "browser": { ... }
  },
  
  "browser": { ... }
}
```

### ШАГ 3: ЕСЛИ СЕКЦИЙ НЕТ

**Возможные причины:**
- Настройки Browser MCP находятся в другом файле
- Настройки не доступны через UI
- Browser MCP использует настройки по умолчанию

---

## 🔧 ЕСЛИ НАСТРОЕК НЕ НАЙДЕНО

**Это нормально!** Browser MCP в Cursor может:
- Использовать настройки по умолчанию
- Не поддерживать конфигурацию через UI
- Требовать настройки через MCP сервер конфиг

**Что делать:**
1. ✅ Использовать текущую оптимизацию (уже работает хорошо!)
2. ❓ Попробовать настроить через MCP сервер (если есть доступ)
3. ✅ Сосредоточиться на других оптимизациях
