# Чеклист раз в 3 дня (пока копим выборку)

Не меняем пороги `P≥80%` / `edge` и не «улучшаем модель по настроению». Только смотрим, что контур живой.

## 1. Учёт результатов
- [ ] В Actions последний прогон зелёный (или понятна причина падения)
- [ ] Есть свежий `football-signals/data/calibration_latest.json`
- [ ] В канале был пост **УЧЁТ РЕЗУЛЬТАТОВ** (после settle) или dry-run файл
- [ ] `pending` не растёт бесконечно по уже сыгранным матчам (если да — смотреть API/status)

## 2. Канал
- [ ] Сводка за день есть даже при 0 ставках
- [ ] Тон спокойный: нет давления «ставьте», дисклеймер на месте
- [ ] VALUE и ВЕРНЯК не путаются в формулировках (edge vs фаворит)

## 3. Операционка
- [ ] Три слота 08/14/20 МСК отработали или есть ручной `workflow_dispatch`
- [ ] В сводке видно: `Прогон: ok`, матчи, очередь учёта
- [ ] Secrets/vars на месте (`PUBLISH_MODE=live`, ключи API/MAX/LLM)

## 4. Честность контента
- [ ] В постах мелькают объяснения edge / «молчаливый день нормален»
- [ ] Нет обещаний плюса «потому что модель умная»
- [ ] При `n < 80` не делаем выводов «система прибыльная/сливная»

## Когда звать агента
- Actions падает 2 раза подряд
- Settle не закрывает finished-матчи
- Hit-rate на `n≥20` ниже средней P модели больше чем на 10 п.п. — только зафиксировать, не чинить сразу
