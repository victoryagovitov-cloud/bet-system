URL:

• Гандбол: https://betboom.ru/sport/handball?period=all&type=live

ПРЕФИЛЬТР (быстрый отбор):

⚽ ФУТБОЛ:
✓ Неничейные счета (не 0:0, не равные)
✓ Коэфф ≤ 2.5
✓ Фаворит ведет в счете
✓ Ставка доступна (нет 🔒)

🎾 ТЕННИС (КРИТИЧНО!):
✓ Коэфф ≤ 2.5
✓ ВАРИАНТ 1: Выиграл 1-й сет + ведет во 2-м
✓ ВАРИАНТ 2: Ведет в 1-м сете 3+ гейма

🚨 ПРОВЕРКА ПЕРЕД ВКЛЮЧЕНИЕМ ТЕННИСА:
❌ НЕ подходит: Счет 1:1 по сетам (это НИЧЬЯ, не победа!)
❌ НЕ подходит: Проиграл 1-й сет, даже если ведет во 2-м
✅ Подходит: Выиграл 1-й сет 6:4 + ведет во 2-м 3:1
✅ Подходит: Ведет в 1-м сете 4:1 (3+ гейма разницы)
✅ Подходит: Выиграл 1-й сет, 2-й еще не начался

🤾 ГАНДБОЛ:
✓ Неничейные счета
✓ Коэфф ≤ 2.5
✓ Фаворит ведет
✓ Ставка доступна

🚨 КРИТИЧНО: ВСЕ МАТЧИ И ВСЕГДА!

ПРАВИЛО (для ФУТБОЛА, ТЕННИСА, ГАНДБОЛА):
- ✅ КАЖДЫЙ матч, прошедший префильтр → ОБЯЗАТЕЛЬНО проверить на Scores24
- ✅ ВСЕ матчи по футболу, теннису, гандболу проверяются
- ✅ ВСЕГДА проверяем, без исключений
- ✅ НЕТ исключений - проверяем ВСЕ матчи из префильтра
- ✅ Не пропускаем ни одного, даже если их 10+
- ✅ Не проверяем только "топ-2" - проверяем КАЖДЫЙ!

Для КАЖДОГО отобранного матча:
1. Открыть на Scores24
2. Подождать 5 сек (начальная загрузка)
3. Сделать snapshot
4. Проверить наличие xG в snapshot:
   • Если xG найден → ГОТОВО ✅ (экономия времени!)
   • Если xG не найден → подождать еще 3 сек → повторить snapshot
5. Извлечь: xG, владение %, удары, H2H (если доступно)
6. БЕЗ этого шага - НЕ отправлять!

⚡ ОПТИМИЗАЦИЯ: Умная проверка готовности вместо фиксированного wait
   Экономия: 30-40% времени без потери качества!
