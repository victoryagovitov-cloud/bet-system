# Обогащение данных через Browser MCP Snapshot

## Проблема
GraphQL запросы к Scores24 не всегда содержат:
- **Минуты для гандбола** (часто = None)
- **Завершенные сеты для тенниса** (нужны для анализа)
- **Минуты для футбола** (иногда отсутствуют)

## Решение
Использовать Browser MCP snapshot страницы Scores24 для получения недостающих данных.

## Как работает

1. **GraphQL остается основным источником** (быстро, есть статистика)
2. **Snapshot используется только для дополнения**:
   - Если минута = None → получаем из snapshot
   - Если нет завершенных сетов (теннис) → получаем из snapshot
3. **Логика работы**:
   - Получаем матчи через GraphQL (как сейчас)
   - Проверяем, кому не хватает данных
   - Делаем snapshot только если нужно
   - Обогащаем данные

## Интеграция

### Файлы:
- `scores24_snapshot_enricher.py` - модуль обогащения
- `generate_live_report.py` - интегрирован вызов обогащения

### Использование:

```python
# В контексте Cursor с MCP Browser:
from generate_live_report import generate_live_report

# Передаем MCP Browser функции
report, matches, meta = generate_live_report(
    max_matches=3,
    mcp_browser_navigate=mcp_cursor-browser-extension_browser_navigate,
    mcp_browser_wait=mcp_cursor-browser-extension_browser_wait_for,
    mcp_browser_snapshot=mcp_cursor-browser-extension_browser_snapshot
)
```

### Без MCP Browser:
Система работает как раньше (без обогащения), если MCP Browser функции не переданы.
