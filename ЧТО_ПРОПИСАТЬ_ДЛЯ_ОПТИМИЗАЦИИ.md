# 📝 ЧТО И ГДЕ ПРОПИСАТЬ ДЛЯ ОПТИМИЗАЦИИ BROWSER MCP

## 🎯 КУДА ПРОПИСАТЬ

### ВАРИАНТ 1: Файл настроек Cursor (settings.json)

**Путь к файлу:**
```
Windows: %APPDATA%\Cursor\User\settings.json
Полный путь: C:\Users\[ИМЯ_ПОЛЬЗОВАТЕЛЯ]\AppData\Roaming\Cursor\User\settings.json
```

**Как открыть:**
1. В Cursor: `Ctrl + Shift + P`
2. Ввести: `Preferences: Open User Settings (JSON)`
3. Enter

---

### ВАРИАНТ 2: Файл конфигурации MCP (если есть)

**Возможные пути:**
```
%USERPROFILE%\.cursor\mcp.json
%APPDATA%\Cursor\mcp.json
%APPDATA%\Cursor\User\mcp.json
```

**Если файла нет - его можно создать!**

---

## ✍️ ЧТО ПРОПИСАТЬ

### ВАРИАНТ A: В settings.json (если есть секция mcpServers)

**Найти или добавить секцию:**
```json
{
  "mcpServers": {
    "browser": {
      "command": "npx",
      "args": [
        "@modelcontextprotocol/server-browser"
      ],
      "env": {},
      "launchOptions": {
        "headless": true,
        "args": [
          "--disable-images",
          "--disable-css",
          "--disable-fonts",
          "--disable-media",
          "--blink-settings=imagesEnabled=false",
          "--disable-background-networking",
          "--disable-background-timer-throttling",
          "--disable-breakpad",
          "--disable-component-extensions-with-background-pages",
          "--disable-default-apps",
          "--disable-dev-shm-usage",
          "--disable-extensions",
          "--disable-features=TranslateUI",
          "--disable-hang-monitor",
          "--disable-ipc-flooding-protection",
          "--disable-popup-blocking",
          "--disable-prompt-on-repost",
          "--disable-renderer-backgrounding",
          "--disable-sync",
          "--disable-translate",
          "--metrics-recording-only",
          "--no-first-run",
          "--safebrowsing-disable-auto-update",
          "--enable-automation",
          "--password-store=basic",
          "--use-mock-keychain"
        ]
      }
    }
  }
}
```

**Что это делает:**
- `--disable-images` → отключает загрузку изображений
- `--disable-css` → отключает CSS
- `--disable-fonts` → отключает шрифты
- `--disable-media` → отключает видео/аудио
- Остальные флаги → оптимизация производительности

---

### ВАРИАНТ B: Только критичные флаги (минимальная версия)

**Если предыдущий вариант слишком сложный, используйте только это:**
```json
{
  "mcpServers": {
    "browser": {
      "launchOptions": {
        "args": [
          "--disable-images",
          "--disable-css",
          "--disable-fonts"
        ]
      }
    }
  }
}
```

---

### ВАРИАНТ C: Если нет секции mcpServers

**Добавить в конец settings.json:**
```json
{
  ... (существующие настройки) ...,
  
  "mcpServers": {
    "browser": {
      "launchOptions": {
        "args": [
          "--disable-images",
          "--disable-css",
          "--disable-fonts"
        ]
      }
    }
  }
}
```

**ВАЖНО:** Не забудьте запятую перед `"mcpServers"` если добавляете в существующий JSON!

## 🔧 ПОШАГОВАЯ ИНСТРУКЦИЯ

### ШАГ 1: Открыть файл настроек

**В Cursor:**
```
Ctrl + Shift + P
→ "Preferences: Open User Settings (JSON)"
→ Enter
```

### ШАГ 2: Проверить структуру файла

**Если файл пустой или минимальный:**
- Добавить всю секцию `mcpServers` (Вариант A или B)

**Если файл большой:**
- Найти есть ли уже `"mcpServers"`
- Если есть - добавить `"browser"` внутри
- Если нет - добавить секцию в конец

### ШАГ 3: Добавить настройки

**Скопировать один из вариантов выше и вставить в файл**

### ШАГ 4: Сохранить и перезапустить

1. Сохранить файл: `Ctrl + S`
2. Перезапустить Cursor
3. Протестировать

## 🔍 ЕСЛИ НЕ РАБОТАЕТ

### Проблема 1: Файл settings.json не содержит mcpServers

**Решение:**
- Browser MCP может использовать встроенную конфигурацию
- Настройки могут быть недоступны через UI
- **В этом случае:** Использовать текущую оптимизацию (уже работает!)

### Проблема 2: После изменений Cursor не запускается

**Решение:**
1. Открыть settings.json
2. Проверить синтаксис JSON (все запятые, скобки)
3. Если ошибка - убрать добавленную секцию
4. Перезапустить Cursor

### Проблема 3: Настройки не применяются

**Решение:**
1. Проверить что файл сохранен
2. Проверить что Cursor перезапущен
3. Проверить логи Cursor (Help → Toggle Developer Tools)
