## 🎯 НАЗНАЧЕНИЕ

Автоматическая проверка финальных результатов матчей и обновление статусов прогнозов в ML файлах.

---

## 📋 КАК ЭТО РАБОТАЕТ

### 1. **Сохранение прогноза**
После отправки сообщения в Telegram:
- Прогноз сохраняется в `predictions_ml_log.json`
- Статус устанавливается как `'pending'`
- Сохраняются все данные: команды, счет, коэффициенты, статистика

### 2. **Проверка результатов**
При каждом запуске анализа:
- Система проверяет все прогнозы со статусом `'pending'`
- Проверяются только прогнозы **старше 90 минут** (матч должен успеть завершиться)
- Для каждого прогноза:
  - Открывается страница завершенных матчей на Scores24
  - Ищется матч по названиям команд
  - Извлекается финальный счет
  - Определяется результат (won/lost/cancelled)
  - Обновляется статус в ML файле

### 3. **Обновление данных**
После проверки:
- Статус меняется: `'pending'` → `'won'` / `'lost'` / `'cancelled'`
- Сохраняется финальный счет
- Рассчитывается прибыль:
  - `won`: `(коэф - 1) * 100`
  - `lost`: `-100`
  - `cancelled`: `0`
- Добавляются ML метрики (правильность прогноза, изменение счета и т.д.)

---

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Файлы:
- **`ml_result_checker_mcp.py`** - модуль проверки результатов через MCP Browser
- **`prediction_logger_ml.py`** - класс для работы с ML файлами
- **`predictions_ml_log.json`** - файл с данными прогнозов

### Функции:
- `check_match_result_mcp()` - проверяет результат одного матча
- `check_pending_results_mcp()` - проверяет все pending прогнозы
- `update_prediction_result_ml()` - обновляет статус прогноза

### Интеграция:
- Автоматически вызывается в `correct_analyzer_with_prefilter.py` (ШАГ 5)
- Использует MCP Browser для доступа к Scores24
- Работает параллельно с основным анализом

---

## ⚙️ НАСТРОЙКИ

### Минимальный возраст прогноза:
- **По умолчанию:** 90 минут
- **Можно изменить:** параметр `min_age_minutes` в `check_pending_results_mcp()`

### Спорты:
- ✅ Футбол
- ✅ Теннис
- ✅ Гандбол

### Статусы:
- `'pending'` - прогноз еще не проверен
- `'won'` - прогноз выиграл
- `'lost'` - прогноз проиграл
- `'cancelled'` - матч завершился ничьей (для футбола/гандбола)

## 🚨 ВАЖНО

1. **Проверка происходит автоматически** при каждом запуске анализа
2. **Не нужно запускать вручную** - система сама найдет старые прогнозы
