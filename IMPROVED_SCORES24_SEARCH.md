# 🔧 УЛУЧШЕННЫЙ АЛГОРИТМ ПОИСКА МАТЧЕЙ НА SCORES24

## ✅ НАДЕЖНЫЙ МЕТОД (ИСПОЛЬЗОВАТЬ ВСЕГДА):

### Шаг 1: Открыть список live матчей
```
https://scores24.live/ru/soccer?matchesFilter=live
```

### Шаг 2: Найти матч в snapshot
- Использовать grep для поиска названий команд
- Искать в snapshot файлах из `agent-tools/`
- Формат поиска: `grep -i "команда1.*команда2\|команда2.*команда1"`

### Шаг 3: Извлечь URL из найденной ссылки
- Найти элемент `<link>` с URL вида `/ru/soccer/m-{date}-{team1}-{team2}`
- Использовать этот URL напрямую

### Шаг 4: Открыть страницу матча
- Добавить базовый URL: `https://scores24.live{найденный_путь}`
- Получить статистику
- **Если получена 404:** сделать вторую попытку (либо повторно открыть URL, либо заново найти через список live). После двух неудач фиксируем, что статистика недоступна и идём дальше.

## ❌ НЕ ИСПОЛЬЗОВАТЬ:

- ❌ Построение URL вручную по названиям команд
- ❌ Предположения о формате slug команд
- ❌ Прямой поиск через URL без проверки
