# 🤖 Инструкция по автоматизации анализа BetBoom

## 🎯 Концепция системы

### Как это работает:
1. **Программа-планировщик** (`chat_scheduler.py`) запускается на твоем ПК
2. **Каждые 30 минут** отправляет сообщение в чат с ассистентом
3. **Ассистент получает запрос** и автоматически:
   - Заходит на BetBoom через Browser MCP
   - Анализирует матчи по алгоритму
   - Отправляет результаты в @TrueLiveBet
4. **Ты получаешь готовый анализ** в канале

---

## 🚀 Запуск системы

### Вариант 1: Простой запуск
```bash
# Двойной клик по файлу:
start_chat_scheduler.bat
```

### Вариант 2: Ручной запуск
```bash
python chat_scheduler.py
```

### Вариант 3: Как служба Windows
```bash
# Запустить от администратора:
setup_30min_scheduler.bat
```

## ⏰ Расписание работы

### Автоматические запросы:
- **09:00** - первый анализ дня
- **09:30** - второй анализ
- **10:00** - третий анализ
- **...каждые 30 минут...**
- **23:00** - предпоследний анализ
- **23:30** - последний анализ дня

### Нерабочее время:
- **00:00 - 08:59** - планировщик спит
- **23:31 - 23:59** - планировщик спит

## 🔧 Настройки планировщика

### Файл конфигурации:
```json
{
  "schedule": {
    "interval_minutes": 30,
    "start_time": "09:00",
    "end_time": "23:30",
    "timezone": "Europe/Moscow"
  },
  "telegram": {
    "bot_token": "7824400107:AAGZqPdS0E0N3HsYpD8TW9m8c-bapFd-RHk",
    "chat_id": "@TrueLiveBet"
  },
  "analysis": {
    "min_probability": 80,
    "min_time_minutes": 60,
    "exclude_draws": true
  }
}
```

### Изменение интервала:
```python
# В chat_scheduler.py измени строку:
schedule.every(30).minutes.do(self.send_analysis_request)
# На:
schedule.every(15).minutes.do(self.send_analysis_request)  # каждые 15 мин
schedule.every().hour.do(self.send_analysis_request)       # каждый час
```

## 📊 Преимущества такого подхода

### ✅ Плюсы:
- **Надежность** - Browser MCP работает стабильно в Cursor

```
Планировщик → Запрос в чат → Browser MCP → Анализ → Telegram

```
