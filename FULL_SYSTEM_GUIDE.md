# 📚 ПОЛНОЕ РУКОВОДСТВО ПО СИСТЕМЕ С ЛОГИРОВАНИЕМ И СТАТИСТИКОЙ

## 🎯 ОБЗОР СИСТЕМЫ

Система состоит из нескольких модулей, которые работают вместе:

### 📦 МОДУЛИ

#### 1️⃣ **Анализ и отправка прогнозов**

- **`full_system_with_logging.py`** - Главный скрипт
  - Получает матчи с BetBoom
  - Применяет умный префильтр
  - Проверяет на Scores24
  - **ЛОГИРУЕТ каждый прогноз**
  - Отправляет в Telegram

- **`full_mcp_with_prefilter.py`** - Логика префильтра и проверки
  - Фильтрация футбола, тенниса, гандбола
  - Интеграция со Scores24

- **`improved_scores24_connector.py`** - Умный поиск на Scores24
  - Транслитерация
  - Множество вариантов названий
  - 100% точность поиска

#### 2️⃣ **Логирование прогнозов**

- **`prediction_logger.py`** - Система логирования
  - Сохраняет каждый прогноз в `predictions_log.json`
  - Хранит: команды, счет, коэффициент, время, категорию
  - Отслеживает статус: pending → won/lost
  - Рассчитывает прибыль

```python
from prediction_logger import PredictionLogger

logger = PredictionLogger()

# Добавить прогноз
pred_id = logger.add_prediction(
    sport='football',
    team1='Команда А',
    team2='Команда Б',
    league='Лига',
    score='2:0',
    odds=1.50,
    category='excellent'
)

# Обновить результат
logger.update_prediction_result(
    prediction_id=pred_id,
    status='won',  # или 'lost', 'cancelled'
    final_score='3:0'
)

# Получить статистику
stats = logger.get_statistics()  # За сегодня
print(f"Процент побед: {stats['win_rate']}%")
print(f"Прибыль: {stats['total_profit']}₽")
```

#### 3️⃣ **Проверка результатов**

- **`result_checker.py`** - Автоматическая проверка результатов
  - Ищет завершенные матчи на Scores24
  - Определяет выиграно/проиграно
  - Обновляет логи
  - Рассчитывает прибыль

```python
from result_checker import ResultChecker

checker = ResultChecker()

# Проверить все прогнозы старше 90 минут
checker.check_pending_predictions(min_age_minutes=90)

# Или проверить все прогнозы за сегодня
checker.check_today_predictions()
```

#### 4️⃣ **Генерация статистики**

- **`daily_stats_generator.py`** - Красивые отчеты
  - Генерирует текстовую инфографику
  - Статистика по видам спорта
  - Статистика по категориям
  - Детали каждого прогноза

```python
from daily_stats_generator import DailyStatsGenerator

generator = DailyStatsGenerator()

# Полный отчет
report = generator.generate_full_report()
print(report)

# Краткая сводка
summary = generator.generate_summary(stats)
print(summary)
```

#### 5️⃣ **Отправка дневного отчета**

- **`send_daily_report.py`** - Отправка итогов дня
  - Проверяет результаты
  - Генерирует отчет
  - Отправляет в Telegram
  - Сохраняет в файл

```bash
python send_daily_report.py
```

#### 6️⃣ **Планировщик отчетов**

- **`daily_report_scheduler.py`** - Автоматическая отправка
  - Запускается в 23:45 МСК каждый день
  - Проверяет все результаты
  - Отправляет итоги

```bash
python daily_report_scheduler.py
```

## 🚀 БЫСТРЫЙ СТАРТ

### 1. Установка зависимостей

```bash
pip install -r requirements.txt

```

```json
  }

```

#### ВАРИАНТ A: Анализ + отправка прогнозов

```bash
python full_system_with_logging.py
```

1. Получит матчи с BetBoom
2. Отфильтрует по критериям
3. Проверит на Scores24
4. **ЗАЛОГИРУЕТ каждый прогноз**

Это проверит все незавершенные прогнозы и обновит их статус.

#### ВАРИАНТ C: Отправка дневного отчета


Это:
1. Проверит результаты всех прогнозов за сегодня
2. Сгенерирует красивый отчет


## 🔧 ИНТЕГРАЦИЯ С СУЩЕСТВУЮЩЕЙ СИСТЕМОЙ

Для интеграции с AutoHotkey скриптом (`cursor_autosend.ahk`):

1. Заменить запуск старого скрипта на:
```autohotkey
Run, python full_system_with_logging.py
```

2. Добавить вечернюю проверку (например в 21:00):
```autohotkey
Run, python result_checker.py
```

3. Запустить планировщик отчетов один раз:
```bash
python daily_report_scheduler.py
```
И оставить его работать в фоне.
