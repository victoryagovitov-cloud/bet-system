# 🤖 Автоматический парсер BetBoom с Browser MCP

## 📋 Что это?
Автоматический парсер, который использует Browser MCP для анализа live матчей на BetBoom по расписанию и находит матчи с высокой вероятностью победы фаворита (>80%).

## 🛠 Установка и настройка

### 1. Предварительные требования
- Python 3.8+ установлен
- Node.js установлен (для MCP Browser)
- Права администратора для настройки планировщика

### 2. Установка зависимостей
```bash
# Установка MCP Browser сервера
npm install -g @modelcontextprotocol/server-browser

# Установка Python зависимостей
pip install -r requirements.txt
```

### 3. Настройка Telegram бота
1. **Бот уже создан**: `@TrueLiveBetBot`
2. **Канал готов**: `@TrueLiveBet`
3. **Токен настроен** в `config.json`
4. **Тестирование**: Запустите `python test_telegram.py`

### 4. Настройка планировщика
1. Запустите `setup_scheduler.bat` **от имени администратора**
2. Задача будет создана с именем "BetBoom_Parser"
3. По умолчанию запускается каждые 30 минут с 09:00 до 23:59

### 5. Настройка конфигурации
Отредактируйте `config.json` для изменения:
- Интервала запуска
- Минимальной вероятности
- Рабочих часов
- Настроек Telegram уведомлений

## 🚀 Использование

### Ручной запуск
```bash
python mcp_betboom_scheduler.py
```

### Управление планировщиком
```bash
# Запуск задачи вручную
schtasks /run /tn "BetBoom_Parser"

# Изменение интервала на 15 минут
schtasks /change /tn "BetBoom_Parser" /ri 15

# Отключение задачи
schtasks /change /tn "BetBoom_Parser" /disable

# Удаление задачи
schtasks /delete /tn "BetBoom_Parser" /f
```

### Просмотр задач
- Откройте `taskschd.msc` для графического интерфейса
- Или используйте: `schtasks /query /tn "BetBoom_Parser"`

## 📊 Результаты

### Файлы результатов
- `betboom_results_YYYYMMDD_HHMMSS.txt` - результаты каждого запуска
- `betboom_parser.log` - логи работы парсера

### Формат вывода
```

💀 Мертвые ставки (>95%)

**Команда А — Команда Б** 🏆 Турнир
⏱ 2Т, 85 мин | Счёт: 2-0
📊 Коэффициент: 1.05 (вероятность 95.2%)
💡 Высокие шансы на сохранение результата
```

## ⚙️ Настройки категорий вероятности

- 💀 **Мертвые ставки** (>95%) - практически гарантированные
- 🎯 **Идеальные ставки** (85-95%) - очень высокие шансы  
- ⭐ **Отличные ставки** (80-85%) - хорошие шансы
- 👍 **Приемлемые ставки** (75-80%) - умеренные шансы

## 🔧 Устранение неполадок

### MCP сервер не запускается
```bash
# Переустановка MCP Browser
npm uninstall -g @modelcontextprotocol/server-browser
npm install -g @modelcontextprotocol/server-browser
```

### Ошибки прав доступа
- Запустите `setup_scheduler.bat` от имени администратора
- Проверьте права на запуск Python скриптов

### Проблемы с браузером
- Убедитесь, что установлен Chrome или Chromium
- Проверьте настройки брандмауэра

## 📱 Добавление Telegram уведомлений

1. Создайте Telegram бота через @BotFather
2. Получите токен бота и chat_id
3. Обновите `config.json`:
```json
"notifications": {
  "enabled": true,
  "telegram": {
    "bot_token": "YOUR_BOT_TOKEN",
    "chat_id": "YOUR_CHAT_ID"
  }
}
```
