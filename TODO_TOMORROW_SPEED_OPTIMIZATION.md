### 4️⃣ ДОБАВИТЬ КЭШИРОВАНИЕ

**Цель:** Ускорить проверку матчей из одной лиги

**Идея:**
```python
# Глобальный кэш таблиц лиг
league_cache = {
    'Portugal_Primeira_Liga': {
        'data': [...],           # Таблица
        'timestamp': 1696532400, # Время загрузки
        'ttl': 3600              # 1 час
    }
}

def get_league_table(league_name):
    # Проверяем кэш
    if league_name in league_cache:
        cache_entry = league_cache[league_name]
        if time.time() - cache_entry['timestamp'] < cache_entry['ttl']:
            print(f"✅ Таблица {league_name} из кэша")
            return cache_entry['data']  # Берем из кэша - 0.1s!
    
    # Загружаем заново
    print(f"📡 Загружаем таблицу {league_name}...")
    table = download_league_table(league_name)  # 8s
    
    # Сохраняем в кэш
    league_cache[league_name] = {
        'data': table,
        'timestamp': time.time(),
        'ttl': 3600
    }
    
    return table
```

**Эффект:**
- Первый матч из Примейры: 8s
- Второй матч из Примейры: 0.1s (берем таблицу из кэша!)
- Третий матч из Примейры: 0.1s

**Приоритет:** СРЕДНИЙ (дает дополнительное ускорение)
