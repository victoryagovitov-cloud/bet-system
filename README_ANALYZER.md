## 📊 ЧТО ЭТО?

Автоматический анализ live-матчей на BetBoom для поиска рекомендаций:
- **Фильтруем** только неничейные матчи [[memory:10987720]]
- **Определяем** фаворита по коэффициентам
- **Проверяем** ведет ли фаворит в счете
- **Рекомендуем** подходящие матчи для ставок

```
20 матчей → 0.35 сек анализа  
Масштабирование: 57+ матчей в секунду
```

## 🔍 КАК ЭТО РАБОТАЕТ?

### Шаг 1: Получить матчи с BetBoom
```
BetBoom LIVE → Парсим HTML → Извлекаем неничейные матчи
Время: 1-2 сек
Пример: "АЗ Алкмаар 0-3 ПСВ" в лайве
```

### Шаг 2: Анализировать каждый матч
```
Для каждого матча параллельно:
  1. Определяем фаворита по кэфам (П1 vs П2)
  2. Проверяем счет: кто ведет?
  3. Если фаворит ведет → РЕКОМЕНДУЕМ
  4. Если нет → ОТКЛОНЯЕМ

Время: 0.01 сек на матч (параллельно)
```

### Шаг 3: Форматируем результаты
```
Выводим список рекомендаций с:
  - Названиями команд
  - Текущим счетом
  - Кэффициентом
  - Рекомендацией для ставки

Время: < 0.1 сек
```

## ⚙️ ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Логика фильтрации:
1. **Ничейные матчи** → ПРОПУСКАЕМ (0:0, 1:1, 2:2)
2. **Неничейные матчи** → АНАЛИЗИРУЕМ

### Определение фаворита:
```
Если П1 < П2:
    Фаворит = Команда 1
Если П2 < П1:
    Фаворит = Команда 2
```

### Определение лидера:
```
Если счет1 > счет2:
    Лидер = Команда 1
Если счет2 > счет1:
    Лидер = Команда 2
```

### Критерий рекомендации:
```
ЕСЛИ фаворит == лидер:
    Рекомендуем ставку на фаворита
ИНАЧЕ:
    Отклоняем матч
```

## 🎓 ОБУЧЕНИЕ

### Понимание алгоритма (2 мин)

1. **Фаворит** = команда с меньшим коэффициентом (бум более вероятна)
2. **Лидер** = команда которая ведет в счете
3. **Рекомендация** = когда фаворит и лидер это одна команда ✓

### Примеры логики:

```
Матч 1: Фаворит(1.5) ведет 2:0 → СТАВКА ✓
Матч 2: Фаворит(1.5) проигрывает 0:2 → ОТКЛОНИТЬ ✗
Матч 3: Аутсайдер(3.5) ведет 3:0 → ОТКЛОНИТЬ ✗
```

## 🚨ТИПИЧНЫЕ ОШИБКИ

### ❌ Неправильно
```
"Матч: Команда1 vs Команда2, счет 0:0"
→ ПРОПУСКАЕМ (ничейный)
```

### ✅ Правильно
```
"Матч: Команда1 vs Команда2, счет 2:1, фаворит команда 1 (кэф 1.6)"
→ Фаворит ведет → РЕКОМЕНДУЕМ
```
